API Endpoint Table

MotorIQ Vehicle Marketplace — Base URL: /api

1. Authentication (/api/auth)

MethodEndpointDescriptionAuth
POST /api/auth/register Register a new user account Public
POST /api/auth/login Login with email & password, returns JWT Public
GET /api/auth/check-email Check if email is already registered Public
POST /api/auth/send-otp Send OTP to user's email for verification Public
POST /api/auth/verify-otp Verify the OTP code sent to email Public

2. Vehicles (/api/vehicles)

MethodEndpointDescriptionAuth
GET /api/vehicles Get all vehicle listings (with premium sorting) Public
GET /api/vehicles/my Get all vehicles listed by the logged-in user Protected
GET /api/vehicles/search Search vehicles with multi-criteria filters Public
GET /api/vehicles/recommend/:id Get AI-recommended similar vehicles Public
GET /api/vehicles/user/:id Get all vehicles by a specific user Public
GET /api/vehicles/:id Get single vehicle details by ID Public
POST /api/vehicles Create a new vehicle listing (multi-image + watermark) Protected
PUT /api/vehicles/:id Update an existing vehicle listing Protected
DELETE /api/vehicles/:id Delete a vehicle listing Public
POST /api/vehicles/:id/boost Submit a premium boost request with deposit slip Protected

3. Users (/api/users)

MethodEndpointDescriptionAuth
GET /api/users/profile Get the logged-in user's profile Protected
PUT /api/users/profile Update user profile (with profile image upload) Protected
PUT /api/users/change-password Change user password Protected
DELETE /api/users/account Delete user account permanently Protected
GET /api/users/favorites Get user's favorite vehicles list Protected
POST /api/users/favorite/:vehicleId Toggle favorite on a vehicle (add/remove) Protected
GET /api/users/:id Get seller's public profile (respects privacy settings) Public (Optional Auth)

4. Chat (/api/chat)

MethodEndpointDescriptionAuth
GET /api/chat Get all chats for the logged-in user Protected
GET /api/chat/:vehicleId/:sellerId Get or create a chat between buyer and seller for a vehicle Protected
POST /api/chat/:chatId Send a message in a chat (supports image attachment) Protected
PUT /api/chat/read/:chatId/:messageId Mark a specific message as read Protected
PUT /api/chat/read-all/:chatId Mark all messages in a chat as read Protected
DELETE /api/chat/:chatId Delete an entire chat Protected
DELETE /api/chat/:chatId/message/:messageId Delete a specific message from a chat Protected

5. Notifications (/api/notifications)

MethodEndpointDescriptionAuth
GET /api/notifications Get user notifications (paginated) with unread count Protected
PUT /api/notifications/read/:id Mark a single notification as read Protected
PUT /api/notifications/read-all Mark all user notifications as read Protected
DELETE /api/notifications/:id Delete a single notification Protected
DELETE /api/notifications Delete all user notifications Protected
POST /api/notifications/broadcast Admin broadcast notification to multiple users Protected

6. Reviews (/api/reviews)

MethodEndpointDescriptionAuth
GET /api/reviews/:vehicleId Get all reviews for a specific vehicle Public
POST /api/reviews/:vehicleId Submit a review and rating for a vehicle Protected

7. Search (/api/search)

MethodEndpointDescriptionAuth
GET /api/search Advanced vehicle search with filters (brand, model, type, price range, location, etc.) Public

8. Price Estimation (/api/price)

MethodEndpointDescriptionAuth
GET /api/price/:id Get AI-estimated fair market price for a vehicle Public

9. Trust Score (/api/trust)

MethodEndpointDescriptionAuth
GET /api/trust/:id Calculate and return trust score for a vehicle listing Public

10. Admin (/api/admin)

MethodEndpointDescriptionAuth
GET /api/admin/stats Get platform statistics (users, vehicles, revenue) Admin Only
GET /api/admin/users Get all registered users Admin Only
DELETE /api/admin/users/:id Delete a user account Admin Only
PUT /api/admin/users/admin/:id Toggle admin privileges for a user Admin Only
PUT /api/admin/users/ban/:id Ban or unban a user Admin Only
GET /api/admin/vehicles Get all vehicles (admin view) Admin Only
DELETE /api/admin/vehicles/:id Delete any vehicle listing Admin Only
GET /api/admin/boosts/pending Get all pending premium boost requests Admin Only
PUT /api/admin/boosts/:id/approve Approve a premium boost request Admin Only
PUT /api/admin/boosts/:id/reject Reject a premium boost request Admin Only
POST /api/admin/notify Send admin notification to specific users Admin Only
